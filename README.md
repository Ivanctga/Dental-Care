Este é um projeto de um site institucional de alto padrão desenvolvido para a clínica **Dental Care**. O foco principal do projeto foi criar uma experiência digital sofisticada, moderna e de alta conversão, refletindo a excelência e o cuidado humanizado oferecidos pela clínica.

---

## 💎 Sobre o Projeto

O site foi construído utilizando as melhores práticas de desenvolvimento front-end, priorizando a performance, a responsividade e a acessibilidade. Com uma estética baseada no conceito de "Luxury Minimalist", o design utiliza uma paleta de cores sóbria, tipografia refinada e micro-animações fluidas para guiar o usuário através da jornada de cuidado odontológico.

### 🌟 Diferenciais do Site
- **Design de Alto Padrão:** Interface visualmente impactante com foco em estética premium.
- **Performance Otimizada:** Carregamento rápido e código limpo (Vanilla JS/CSS).
- **Foco em Conversão:** CTAs (Call to Action) estrategicamente posicionados para agendamento de consultas.
- **Responsividade Total:** Experiência perfeita em smartphones, tablets e desktops.
- **SEO Ready:** Estrutura semântica preparada para motores de busca.

---

## 🚀 Funcionalidades

- **Header Inteligente:** Menu fixo que se adapta ao scroll para navegação facilitada.
- **Hero Section:** Apresentação impactante com estatísticas de sucesso da clínica.
- **Seção "Sobre a Clínica":** Stack de imagens modernas e cards flutuantes com diferenciais.
- **Grid de Serviços:** Exibição elegante dos tratamentos oferecidos com ícones personalizados.
- **Slider de Depoimentos:** Carrossel interativo desenvolvido em Vanilla JS para prova social.
- **Galeria Antes & Depois:** Comparativo visual de casos clínicos reais.
- **FAQ Accordion:** Seção de dúvidas frequentes com animações suaves.
- **Formulário de Contato:** Validação em tempo real e integração visual moderna.
- **Animações de Revelação (Scroll Reveal):** Conteúdo que surge suavemente conforme o usuário navega.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido sem dependências externas pesadas (frameworks), garantindo leveza e total controle sobre o código:

- **HTML5:** Estrutura semântica e acessível.
- **CSS3 (Vanilla):** Sistema de design personalizado com variáveis CSS, Flexbox e Grid.
- **JavaScript (Vanilla):** Lógica de animações, slider, FAQ e validação de formulário.
- **Font Awesome:** Ícones vetoriais de alta qualidade.
- **Google Fonts:** Tipografia refinada (Inter e Poppins).
